# 072-arena-z-proposer-migration

Status: DRAFT

## Objective

Updates the proposer address in the DisputeGameFactory for Arena-Z Testnet (Chain ID: 9899) on Sepolia.

This is part of the Arena-Z Chain Servicer Migration. The proposer address in the PermissionedDisputeGame CWIA args
is updated from `0xC97FFcB0953e60995B5D06755DEd41b78A3C8B48` to `0x5D7481c68Eb61da46b2F4eF81B9FD988d97527E0`.

The implementation contract (`0x58bf355C5d4EdFc723eF89d99582ECCfd143266A`) remains unchanged.

## Transaction creation

The transaction is generated by the [SetDisputeGameArgs template](../../../template/SetDisputeGameArgs.sol),
which reads the inputs from the [`config.toml`](./config.toml) file.

## Signing and execution

Follow the instructions in the [Nested Execution](../../../NESTED.md) guide.
